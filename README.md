# Retro Digital Clock & Factorial Calculator

A simple web app that combines a retro-style digital clock and a factorial calculator. Users can switch between various themes for a dynamic and engaging experience. The app features both iterative and recursive methods for calculating the factorial of a given number.

## Features

- **Digital Clock**: A real-time updating digital clock with various theme styles.
- **Factorial Calculator**: Calculates the factorial of a number using both iterative and recursive methods.
- **Theme Selector**: Allows users to switch between different themes:
  - Dark
  - Light
  - Retro
  - Ocean
  - Sunset
  - Cyberpunk

## Technologies Used

- **HTML5**: Markup structure for the web page.
- **CSS3**: Styling for the app and responsive design.
- **Bootstrap 5**: Used for layout and responsive design.
- **JavaScript**: For dynamic clock functionality, factorial calculations, and theme switching.
